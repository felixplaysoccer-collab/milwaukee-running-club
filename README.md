# Milwaukee Running Club Website

A responsive website layout developed for INFOST 320: Web Design II at the University of Wisconsin–Milwaukee (Fall 2026).

## Overview

This coursework project demonstrates HTML and CSS layout techniques using a three-column page about a fictional running club.

## Features

- Navigation and content sections for Training Tips, Upcoming Races, and Featured Runner
- CSS Flexbox for page layout and ordering
- Responsive media queries for smaller screens
- Footer with links and social icons

## Technologies

- HTML5
- CSS3 (including Flexbox and media queries)
- Netlify for hosting

## Live Demo

[Milwaukee Running Club website](https://jolly-baklava-b558cd.netlify.app/)

## Run Locally

Open `index.html` in a web browser. Styles are embedded in the HTML file; some images, icons, and fonts are loaded from external URLs.
